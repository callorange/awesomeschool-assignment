## 문서 관리 원칙

- 각 규칙은 담당 문서 한 곳에 정의하고 다른 문서에서는 링크로 참조합니다. README의 빠른 소개와 실행에 필요한 설명은 유지하되, 정책의 상세 정의를 반복하지 않습니다.
- 독립된 주제가 생기거나 기존 문서에서 해당 주제를 따로 찾고 유지하기 어려워지면 `docs/`에 문서를 분리하고 이 표와 관련 링크를 함께 갱신합니다. 분량만을 기준으로 파일을 나누지 않습니다.
- 규약 변경 시 담당 문서와 영향을 받는 참조를 함께 수정합니다. 설정값·의존성의 실제 선언은 코드와 설정 파일을 기준으로 확인합니다.
- Git에서 제외된 `AGENTS.md`는 에이전트 전용 실행 지침과 이 문서의 참조를 유지합니다. 공유 규약을 그 파일에만 기록하지 않습니다.
- `openspec/config.yaml`은 짧은 프로젝트 맥락, 이 문서의 참조와 artifact·operation 지침을 유지합니다. 공통 규약 전문을 복제하지 않습니다.
- OpenSpec change와 archive는 변경 당시의 기록이며 현재 공통 규약의 원본으로 사용하지 않습니다.
