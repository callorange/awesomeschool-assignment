# 교육 신청 시스템 구현 과제

교육 서비스의 핵심 흐름인 “교육 소개 → 신청 접수 → 신청 관리”를 간단한 형태로 구현해 주세요.
이번 과제는 실제 서비스 운영을 염두에 두고, 신청 데이터의 수집·관리·안내 흐름을 어떻게 설계하는지 확인하기 위한 것입니다.

개발 기간이 길지 않다는 점을 고려하니, 모든 항목을 완성하기보다 본인이 구현 가능한 범위까지 완성도 있게 제출해 주세요.

## 기한

4일 (메일 수신일로부터)

## 필수 구현 과제

### 교육 소개 페이지

- 교육명, 한 줄 소개, 커리큘럼, 대표 이미지 등을 보여주는 랜딩 페이지를 구현해 주세요.
- 디자인과 구성은 자유롭게 구성하되, 정보 전달이 명확하면 됩니다.
- 샘플 데이터 또는 히어로스쿨의 교육 콘텐츠를 사용해도 됩니다.

### 교육 신청 페이지

- 이름, 이메일, 주소, 연락 가능 날짜를 입력받는 신청 폼을 구현해 주세요.
- 반응형 레이아웃을 고려해 주세요.
- Ajax를 활용한 비동기 처리 또는 페이지 일부 갱신이 가능하면 좋습니다.

### 신청 관리 기능

- 제출된 신청 데이터를 저장·조회·수정·삭제할 수 있어야 합니다.
- 신청 상태를 구분할 수 있으면 좋습니다. 예: 접수 / 확인중 / 완료
- Django admin 또는 별도의 관리자 화면을 활용해도 무방합니다.

### 백엔드 및 API

- Django와 PostgreSQL을 사용해 모델을 설계해 주세요.
- 교육 신청 관련 간단한 GET/POST API를 DRF로 구현해 주세요.
- 연락 가능 날짜 기준으로 자동 안내 메일을 전송하는 기능이 있으면 좋습니다.

## 우대 구현 과제

- 신청 목록을 보는 관리자 전용 페이지 구현
- Google Spreadsheet API 연동을 통한 신청 목록 내보내기
- AWS 사용 계획 또는 배포 구성 작성
- AI 코딩 보조 도구 사용 내역과 활용 이유 정리
