# Spec Delta

## ADDED Requirements

### Requirement: 초기 교육의 운영 정보
고정 교육 3개의 프리셋은 코치 출강 운영 방식·일정과 진행 조건을 상담 후 협의한다는 안내·상담 접수 활성 여부를 명시해야 한다(SHALL). 안내는 과제의 접수 정책임을 편집 설명으로 구별하고 확인되지 않은 원본의 가격·정원·지역·모집기간을 확정 정보로 제공하지 않아야 한다(SHALL).

#### Scenario: 빈 DB의 운영 정보 설정
- **WHEN** migration 후 초기 데이터 명령으로 빈 DB를 설정한다
- **THEN** 기존 교육 3개와 이미지가 생성되고 각 교육의 운영 방식·진행 안내·상담 접수 상태가 프리셋과 일치한다

#### Scenario: 편집한 운영 정보의 재실행 보존
- **WHEN** 기존 교육의 운영 방식·진행 안내·상담 접수 상태를 수정한 후 초기 데이터 명령을 다시 실행한다
- **THEN** 수정한 값과 기존 콘텐츠·이미지가 유지되고 중복 교육이 생성되지 않는다

### Requirement: 초기 데이터와 교육 입력 검증의 일치
초기 데이터 명령은 교육 입력과 동일한 운영 방식·목표·추천대상·커리큘럼 검증 계약을 사용해야 한다(SHALL). 프리셋 전체의 콘텐츠 또는 이미지 입력에 오류가 있으면 기존 부분 저장 방지 계약에 따라 DB와 저장소 쓰기를 시작하지 않아야 한다(SHALL).

#### Scenario: 운영 방식 또는 콘텐츠가 잘못된 프리셋
- **WHEN** 프리셋에 정의되지 않은 운영 방식이나 교육 입력 검증에서 거부하는 목표·추천대상·커리큘럼이 있다
- **THEN** 초기화 실패를 식별 가능한 오류로 보고하며 해당 실행으로 교육과 이미지를 생성하지 않는다

#### Scenario: 공통 검증으로 전환한 뒤 저장 실패
- **WHEN** 유효한 프리셋을 저장하는 과정에서 저장소 또는 DB 오류가 발생한다
- **THEN** 기존 DB 롤백·잔여 파일 안내·재실행 시 파일 재사용 계약이 유지된다

### Requirement: 교육별 프리셋 이미지 경로와 재사용
신규 프리셋 이미지 파일은 프리셋에 기록한 교육별 고정 UUIDv7의 32자 hex images 하위 경로와 원본 내용의 SHA256 파일명을 사용해야 한다(SHALL). 기존 교육의 이미지 키는 변경하지 않으며, 초기화 재실행과 실패 후 재실행에서는 같은 원본의 새 규칙 경로에 남은 파일을 재사용해야 한다(SHALL). 저장소가 이름을 조정하면 반환된 이름을 참조해야 한다(SHALL). media_id의 누락·잘못된 형식·UUIDv7이 아닌 값·프리셋 내 중복은 DB·파일 쓰기 전에 거부해야 한다(SHALL).

#### Scenario: 신규 교육의 이미지 저장
- **WHEN** 빈 DB와 저장소에 교육 3개를 초기화한다
- **THEN** 이미지가 각 교육의 images 하위 경로에 SHA256 기반 PNG 파일명으로 저장되고 실제 저장 키가 교육에 연결된다

#### Scenario: 기존 교육과 이미지의 보존
- **WHEN** 기존 형식 경로의 이미지를 참조하는 교육이 있는 상태에서 초기화 명령을 실행한다
- **THEN** 해당 교육의 이미지 키·파일·운영 정보는 보존되고 없는 교육에 필요한 이미지 저장만 새 경로 규칙을 사용한다

#### Scenario: 실패 잔여 파일의 재사용과 재생성
- **WHEN** 앞선 실패로 새 규칙 경로의 이미지가 남아 있거나, 교육 삭제 후 파일 정리가 끝난 상태에서 초기화를 재실행한다
- **THEN** 남아 있는 같은 원본 파일은 재사용하고 정리되어 없는 파일은 다시 생성하며 기존 연결 파일을 덮어쓰지 않는다

### Requirement: 수집 기록과 운영 필드의 분리
source_url·source_image_url·collected_on·editorial_note는 프리셋 JSON에만 보관하고 Education 모델에 저장하지 않아야 한다(SHALL). 초기화는 이 값을 모델 생성 인자에서 제외해야 한다(SHALL).

#### Scenario: 수집 기록이 포함된 프리셋 초기화
- **WHEN** 수집 기록과 교육 운영 필드가 함께 있는 JSON으로 초기화한다
- **THEN** 교육 3개와 이미지는 정상 생성되고 수집 기록은 JSON에 남으며 DB 열에는 존재하지 않는다
