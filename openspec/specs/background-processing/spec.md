# background-processing Specification

## Purpose

신청 안내와 이미지 정리를 웹 요청 밖에서 실행하고, 기존 PostgreSQL을 활용해 대기 작업과 실패를 추적하게 한다. 작은 운영 구성으로 시작하면서 transaction rollback·작업 재전달·정상 종료 시 데이터와 외부 side effect의 경계를 보존한다.

## Requirements

### Requirement: 단일 기본 큐와 독립 실행

시스템은 기존 PostgreSQL에 기반한 기본 큐 하나와 웹 서버와 별도인 실행 명령 하나로 메일·이미지 작업을 처리해야 한다(SHALL). 별도 Redis·대체 cluster·전용 DLQ를 요구하지 않아야 한다(SHALL). 동시 실행 수는 고정 설정으로 조절하고 변경 후 정상 재시작해야 한다(SHALL).

#### Scenario: 개발 worker 실행
- **WHEN** DB와 migration을 준비한 개발 환경에서 기본 worker 명령을 실행한다
- **THEN** AWS 자격 증명 없이 기본 큐의 작업과 날짜별 검사를 처리하고 메일은 모의 처리하며 이미지 정리는 로컬 저장소를 사용한다

### Requirement: transaction과 작업 등록의 일관성

DB 변경을 전제로 하는 작업은 변경 commit 전에 실행되지 않아야 하며 rollback된 변경의 작업은 남지 않아야 한다(SHALL). 신청 안내는 DB의 영속 대상에서 재등록할 수 있어야 하고 이미지 변경·삭제는 정리할 키와 작업을 영속적으로 등록하거나 DB 변경을 실패로 처리해야 한다(SHALL).

#### Scenario: 작업 등록 후 rollback
- **WHEN** 이미지 교체·교육 삭제 또는 신청 생성 transaction을 rollback한다
- **THEN** 해당 변경을 전제로 한 신규 작업·안내 대상이 남지 않고 기존 데이터와 파일이 보존된다

#### Scenario: 큐 등록 오류
- **WHEN** 이미지 변경에 필요한 큐 기록 저장 또는 안내 작업 등록이 실패한다
- **THEN** 이미지 DB 변경은 정리 키를 잃은 채 성공하지 않으며 안내 대상은 보존되어 복구 후 재등록된다

### Requirement: 작업 종류별 실패 정책

작업별로 실패 자동 재시도 여부를 구분하고 재전달 대기 시간을 내부 대기·실행·결과 저장 시간보다 길게 구성해야 한다(SHALL). 메일은 발송 기록의 분류에 따라 재등록하고 이미지 삭제는 총 3회 시도 후 실패를 보존해야 한다(SHALL). 실패 목록은 원인·시도·수동 재등록을 확인할 수 있어야 한다(SHALL).

#### Scenario: 이미지 삭제와 메일 실패
- **WHEN** 이미지 저장소 오류와 발송 결과가 불명확한 메일 오류가 각각 발생한다
- **THEN** 이미지는 설정된 한도 내에서 재시도하고 메일은 자동 재전송하지 않으며 각 결과는 관리 목록·발송 기록으로 구분해 확인할 수 있다

#### Scenario: 실패 작업 재등록
- **WHEN** 원인을 해결하고 실패한 이미지 작업을 수동 재등록한다
- **THEN** 최신 참조를 검사하고 이미 없어진 파일은 완료로 처리하며 다른 파일을 대신 삭제하지 않는다

### Requirement: 정상 종료와 재전달 안전성

정상 종료 요청 시 새 작업 수신을 멈추고 내부 대기·실행 작업과 결과 처리를 마친 뒤 종료해야 한다(SHALL). 실행·외부 I/O와 종료 유예 시간을 유한하게 구성하고 강제 종료 뒤 재전달되는 작업도 기존 발송·이미지 보호 조건을 지켜야 한다(SHALL).

#### Scenario: 처리 중 정상 종료
- **WHEN** 제어 가능한 진행 중 작업과 내부 대기 작업이 있는 상태에서 정상 종료 신호를 보낸다
- **THEN** 종료 전 각 결과가 DB에 기록되고 broker에 아직 남은 작업은 다음 실행에서 처리된다

#### Scenario: 강제 종료 후 재시작
- **WHEN** 작업 처리 중 프로세스가 강제로 종료된 뒤 다시 실행된다
- **THEN** 미처리 작업을 복구하되 결과 불명 메일을 무조건 발송하거나 참조 중 이미지를 삭제하지 않는다
